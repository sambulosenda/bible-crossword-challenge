# Cloudflare's managed robots.txt is ON for this zone, so what visitors actually
# receive is Cloudflare's block PREPENDED to this file. Cloudflare sets
# `Content-Signal: ai-train=no` and disallows the training crawlers (GPTBot,
# ClaudeBot, Google-Extended, Applebot-Extended, CCBot, Amazonbot, Bytespider,
# meta-externalagent).
#
# Those crawlers are deliberately NOT named below. Listing them here with
# `Allow: /` would put two contradicting groups in one file for the same agent,
# and parsers disagree on which wins — an ambiguous file is worse than either
# policy on its own. Silence leaves Cloudflare's rule to stand cleanly.
#
# What is named below is everything Cloudflare permits: the search engines, and
# the AI assistants that fetch a page at answer time rather than for training.
# Those are the ones that can surface and cite the app today, so they are made
# explicit — a future blanket rule can never silently drop them.
#
# To allow training as well, turn the managed setting off first (Security →
# Settings → Bot traffic), then add the training agents back here. Changing only
# this file will not do it.

User-agent: *
Allow: /
